# Pixel Tools

Static website with free browser-based image tools:

- Image to WebP converter
- Image compressor
- Pro image resize/editor
- About and privacy pages
- SEO metadata and room to add AdSense after approval

## Before publishing

Ad banners and AdSense scripts are currently removed. After AdSense approval, add your real Google AdSense client ID, ad slot IDs, and update `ads.txt` with your real `pub-` publisher ID.
Replace the contact placeholder in `privacy.html` with your real contact method.

## Deployment

Upload the files to any static host. `robots.txt` and `ads.txt` should be available from the root of the live domain.
